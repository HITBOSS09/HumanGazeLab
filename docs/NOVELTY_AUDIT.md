# Novelty audit

Read on 14 November 2026. A row is included only when the source page, PDF text, or repository page was retrieved in this audit. Numerical claims are limited to figures that appeared in that retrieved text. This file does not declare a research gap from papers that were not opened.

The proposed track is a publication-quality contribution on cross-dataset temporal uncertainty, observer variability, measurement protocols, and visual-feature dependence. The verdict below is about that proposal. It is not a claim that the proposal is novel.

## What this repository actually computed

The frozen models are binned kernel densities: center bias, same-image leave-one-observer, same-index leave-one-observer (B3), and a previous-fixation kernel. They are not DeepGaze, HAT, ScanDiff, or the ICCV 2025 dataset-bias model. Official code for those systems was not run. No numerical score from this repository is a comparison against those papers.

## Verdict

The proposed direction is not a demonstrated new empirical finding.

1. Already addressed, for the questions those papers asked: temporal decay of fixation predictability and a stable history effect (DeepGaze III and the 2022 abstract); spatial cross-dataset bias, including blur in degrees and few-shot adaptation (ICCV 2025); free-viewing scanpath prediction on COCO-FreeView together with OSIE and MIT1003 (HAT, CVPR 2024); index-aware population fixations, observer identity, and leave-one-dataset-out scanpath likelihood (DeepGaze3.5-VL); diversity of generated scanpaths (ScanDiff).
2. A replication would be running one of those official implementations on its own split. That was not done.
3. A methodological sensitivity, not a new model class: the controls in `outputs/protocolshift_b3_v1/` ask whether this repository's B3 sign difference survives observer count, index alignment, bandwidth, probability floor, and canvas-fraction coordinates. The retrieved papers do not report that estimator's −0.314 versus +1.848 contrast. Absence of this exact table from the pages read here is not evidence that the scientific question is open.
4. Not established. The residual after the joint control is a description of already inspected splits. It was not held out from the analyst, and it was not tested in degrees of visual angle.
5. Unresolved as a measurement, and only as a measurement: visual-angle alignment of these two releases, an untouched confirmatory partition, and any comparison that uses the official code on a matched split.

Calling the track a publication-quality contribution would require a hypothesis the investigator writes, a baseline that is actually run, and a confirmatory partition that these controls do not have.
